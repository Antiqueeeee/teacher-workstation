# 班主任工作台（重构版）

把一个买来的「单文件网页应用」（所有数据存在浏览器 localStorage 里）重构为**前后端分离、数据持久化、可在离线内网使用**的项目。

- 原应用：`raw-material/web-app/班主任工作台.html`（18995 行单文件，只读参考，不再修改）
- 设计文档：`docs/改造方案/`（**动手前先读**）
- 开发约定：`CONTRIBUTING.md`（分层禁令、单文件 600 行上限、离线硬规则）

---

## 要解决的问题

1. **数据不再存在浏览器缓存里** —— 从 localStorage 单键搬到 SQLite + 媒体目录。
2. **复刻现有 33 个页面的功能**，逻辑从「前端直读直改全局数据」改为「前端调后端 API」。
3. **三处确定的调整**：
   - 宿舍分布配置时会出现意义不明的报错（根因是数据模型错了，见 `04` §1）；
   - 作业提交率目前靠用户手填，改为后端自动计算（`04` §2）；
   - 新增照片与音频**归档**（录音由老师用手机自行完成，本项目只负责存档，`04` §3）。

## 已确定的关键约束

| 约束 | 说明 |

## 快速开始

**老师怎么用**：把整个文件夹解压到自己的电脑上 → **双击「启动」** → 浏览器自动打开界面，
黑窗口里会写明「手机该访问哪个地址」。详见 **`使用说明.md`**。

不用装 Python、不用装数据库、不用装 Docker —— 交付包自带 Python 运行时（`runtime/`），
数据全在这个文件夹的 `data/` 目录里（整包拷走就是备份）。

开发机上怎么跑：

```bash
# 1. 装依赖（用仓库里的 .validation/conda，Python 3.11）
../.validation/conda/python.exe -m pip install -r backend/requirements-dev.txt

# 2. 起服务（开发模式：热重载；手机与电脑都通过内网地址访问）
cd backend
PYTHONPATH=. ../.validation/conda/python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8723 --reload
# → http://<本机内网IP>:8723/

# 或者用一键启动器（与老师那条路完全一致，含后台/停止/状态）
../.validation/conda/python.exe launcher.py            # 前台
../.validation/conda/python.exe launcher.py --daemon   # 后台
../.validation/conda/python.exe launcher.py --stop     # 停止

# 3. 跑测试
cd backend && PYTHONPATH=. ../.validation/conda/python.exe -m pytest -q

# 4. 提交前检查
python tools/check_file_size.py
python tools/check_frontend.py
python tools/check_launch_scripts.py
```

首次启动会自动建目录、跑迁移，并创建一个**空的**默认班级（不是演示数据）。
数据目录默认是**包根目录的 `data/`**（不是 `backend/` 里），可用 `TWS_DATA_DIR` 覆盖。
